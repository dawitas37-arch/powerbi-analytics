# Monthly Operations Analytics | Power BI Portfolio

## Project Overview

This project is based on the type of reporting and analytics work I do in my current role as a Data Engineer at Publicis Sapient, supporting HRSA.

In my role, I work with SQL Server, Power BI, Power Query, DAX, and reporting automation to improve data processing and business reporting.

**To protect company confidentiality, I have not uploaded any actual company data, internal reports, or database connections to GitHub.**

Instead, I independently built a similar Power BI dashboard using 100% synthetic data to demonstrate my technical skills and reporting experience.

The project includes three report pages:

- **Monthly Operations Overview:** KPIs for total, completed, pending, and overdue requests, along with monthly trends and interactive filters.
- **Operational Details:** Request analysis by team, region, and service category.
- **Quality & Exceptions:** Overdue request tracking, quality flags, and average resolution time.

## Technologies Used

Power BI Desktop | SQL Server | DAX | Power Query | Data Modeling | Data Visualization
